## 🎮 Question Types Explained

### **1. Knowledge Check Questions (10 per lesson)**

#### **Format:**
- Multiple choice with 4 options (A, B, C, D)
- One correct answer with detailed explanation
- Code examples where applicable
- Helpful hints for students

#### **Difficulty Levels:**
- 🟢 **Easy** (10 XP): Basic concepts, definitions, syntax
- 🟡 **Medium** (15 XP): Application of concepts, code analysis
- 🔴 **Hard** (20 XP): Complex scenarios, edge cases, best practices

#### **Example Question:**
```
Q: What is the main purpose of object-oriented programming?

A. To organize code into reusable objects that model real-world entities ✅
   → Correct! OOP helps organize code by modeling real-world entities.

B. To make programs run faster ❌
   → Incorrect. While OOP can improve efficiency, its main purpose is code organization.

C. To reduce the number of lines of code ❌
   → Incorrect. OOP focuses on code organization, not necessarily reducing lines.

D. To eliminate all bugs in programs ❌
   → Incorrect. No paradigm can eliminate all bugs.

[EASY] [KNOWLEDGE CHECK] [10 XP]
💡 Hint: Think about how OOP models real-world concepts in code.
```
