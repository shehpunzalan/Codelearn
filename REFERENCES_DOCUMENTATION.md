# References Documentation - CodeLearn AI

## Overview
All 111 lessons in the CCS108 - Object-Oriented Programming with Java course now include comprehensive academic references and learning resources citations. This ensures proper attribution and provides students with additional resources for deeper learning.

## Reference Locations

### 1. Video Tutorial Page
**Location:** When students click "Video Tutorial" in any lesson

**What's Displayed:**
- **Video Source Citation:** Full academic citation for the YouTube video
  - Format: `Channel Name. (Year). Video Title [Video]. YouTube. URL`
  - Example: `YouTube. Introduction to Java Programming [Video]. YouTube. https://youtu.be/3LY9f9WbSbU`
- **Description:** Comprehensive description of the video content
- **Duration:** Video length
- **Channel Information:** Channel name and URL
- **Direct Links:** "Open in YouTube" button for external viewing

**Visual Design:**
- Purple and blue gradient header matching CodeLearn AI branding
- Dedicated citation box with Video icon
- Clean, professional layout following University of Cabuyao UI rubric standards

## Citation Format Standards

All citations follow **APA 7th Edition** format, which is the standard for academic work:

### Video Citations
```
Author/Channel. (Year). Title [Video]. Platform. URL
```

### Book Citations
```
Author, A. A. (Year). Title of work (Edition). Publisher.
```

### Web Documentation
```
Organization. (Year). Title. Organization Name. URL
```
