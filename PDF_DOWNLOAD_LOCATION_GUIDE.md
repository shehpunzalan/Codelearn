## 🎓 **TROUBLESHOOTING**

### **Can't Find the Button?**

**Check:**
1. ✅ Are you logged in as a **Student**? (Not instructor)
2. ✅ Are you on the **Dashboard** page?
3. ✅ Is the **right sidebar** visible? (Scroll if needed)
4. ✅ Look for **"Student Actions"** heading
5. ✅ Scroll down in the Actions section

### **Button Not Working?**

**Try:**
1. 🔄 Refresh the page
2. 🖱️ Click directly on the button text
3. ⏳ Wait a few seconds after clicking
4. 📱 Check browser's download folder
5. 🔔 Enable browser pop-ups/downloads

### **PDF Not Downloading?**

**Solutions:**
1. 📂 Check Downloads folder
2. 🔓 Allow downloads in browser settings
3. 🌐 Try a different browser
4. 💾 Check available disk space
5. 🔄 Clear browser cache and try again
