## Color & Badge System

### Student Portal Indicators
- **Badge:** `[Student Portal]` - Green border, green text
- **Primary Color:** Blue gradient
- **Accent:** Purple
- **Focus:** Personal metrics

### Instructor Portal Indicators
- **Badge:** `[Instructor]` - Blue border, blue text
- **Primary Color:** Purple gradient
- **Accent:** Blue
- **Focus:** Class metrics

---

## Navigation Comparison

| View | Student | Instructor |
|------|---------|------------|
| **Dashboard** | Personal stats, AI insights for self | Class stats, patterns, student monitoring |
| **Modules** | Browse and learn | Manage content, create modules |
| **Feedback** | View own AI feedback | N/A |
| **Progress** | Track personal progress | N/A |
| **Analytics** | N/A | Comprehensive class analytics |
| **Monitoring** | N/A | Real-time activity feed |

## Key Visual Differences

### Student Dashboard:
- ✅ Personal achievement focus
- ✅ Individual progress tracking
- ✅ AI coaching and recommendations
- ✅ Learning journey emphasis
- ✅ Warm, encouraging tone

### Instructor Dashboard:
- ✅ Class-wide overview
- ✅ Teaching insights
- ✅ Problem detection and alerts
- ✅ Data-driven decisions
- ✅ Professional, analytical tone

### Student Actions:
1. 📚 Access Modules

1. 📊 Access Student Analytics
2. 🔍 Monitoring & Evaluation
3. 📚 Course Management
4. ➕ Create Activities
5. 📥 Export Analytics

---

## Summary

The dashboard separation provides:
- **Clear role distinction** through badges and navigation
- **Tailored experiences** for students vs instructors
- **Appropriate data scope** (personal vs class-wide)
- **Role-specific actions** aligned with use case diagram
- **Visual consistency** with color-coded themes
