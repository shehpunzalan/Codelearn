## 🔍 Finding References - Quick Tips

1. **Look for the gradient** → Indigo/Purple background
2. **Scroll to bottom** → Section 6 in lessons
3. **Click the icon** → BookMarked (📚) symbol
4. **Count the cards** → Should see 6 references
5. **Try the links** → Blue buttons with 🔗 icon

When viewing references, you should see:
- [ ] Purple/Indigo gradient background
